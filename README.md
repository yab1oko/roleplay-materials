# Roleplay Materials

**Roleplay Materials** adds a small set of crafting / loot items for adventure and roleplay maps.

Includes scrap, wood, planks, cloth, pipes, nails, glue, tape, sewing kit, chemicals, pebbles, old money, tickets, and keys with multiple textures.

Works as a dependency for [CTS](https://www.curseforge.com/minecraft/mc-mods/custom-loot-system) and [Cold Weapons](https://www.curseforge.com/minecraft/mc-mods/cold-weapons) crafts and drops. The mod is useful on its own as a materials pack for mapmakers.
