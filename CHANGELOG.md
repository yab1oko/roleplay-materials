# Changelog

## 1.1
- Crafting pipeline for forged iron: scrap → nugget (campfire / blast furnace) → ingot → plate
- Plate craft uses a hammer (`#forge:tools/hammers`) and damages the tool instead of consuming it
- Wood + axe → 2 planks (damages the axe); 4 planks → oak planks block
- Pebble → flint (shapeless)
- New parts: circuit, motor, mace head, circular saw blade, chainsaw bar, machete blade
- Crafts for motor, mace head, circular saw, chainsaw bar, and machete blade
- New forged iron item textures (nugget / ingot / plate)
